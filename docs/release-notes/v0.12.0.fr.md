- Disposition : Détecter les écrans relit les écrans de chaque machine connectée et affiche sur chacun lequel il est, avec le nom et la couleur de sa machine ; sur la carte, chaque écran porte le nom de sa machine.
- Un écran éteint ou débranché est conservé comme déconnecté, avec ce que les profils en font, au lieu d'être supprimé. DeskBridge lit les écrans de ce PC dans Windows au démarrage et s'ouvre sur le profil appliqué.
- Les fenêtres d'une machine posées sur l'image de l'ordinateur de bureau sur son écran s'utilisent là où elles sont : la souris passe à cette machine au-dessus d'elles. Celles qui s'ouvrent derrière l'image sont déplacées là où la souris les atteint.
- Une tablette peut afficher l'écran du portable, relayé par l'ordinateur de bureau, avec le curseur qui suit ; l'écran de verrouillage et les demandes d'administrateur s'affichent aussi sur un écran prêté.
- Corrections : les écrans virtuels sont placés comme la carte les montre (une fenêtre sortie de l'un n'apparaît plus sur un autre écran) ; un écran principal prêté en laisse un autre utilisable ; plus aucun écran virtuel de trop dans les paramètres d'affichage de Windows.
