- Disposició: Detecta les pantalles torna a llegir les pantalles de cada equip connectat i mostra a cadascuna quina és, amb el nom i el color del seu equip; al mapa cada pantalla porta el nom del seu equip.
- Una pantalla apagada o desendollada es conserva com a desconnectada, amb el que en fan els perfils, en lloc d'esborrar-se. DeskBridge llegeix les pantalles d'aquest PC de Windows en arrencar i obre amb el perfil aplicat seleccionat.
- Les finestres d'un equip que queden damunt de la imatge de l'ordinador de sobretaula a la seva pantalla es poden fer servir on són: el ratolí passa a aquell equip per sobre d'elles. Les que s'obren darrere de la imatge es porten on arriba el ratolí.
- Una tauleta pot mostrar la pantalla del portàtil, retransmesa a través de l'ordinador de sobretaula, amb el cursor seguint-la; la pantalla de bloqueig i els avisos d'administrador també es veuen en una pantalla cedida.
- Correccions: les pantalles virtuals es col·loquen com les mostra el mapa (una finestra arrossegada fora d'una ja no apareix en una altra pantalla); una pantalla principal cedida en deixa una altra d'utilitzable; no queda cap pantalla virtual sobrant a la configuració de pantalla de Windows.
