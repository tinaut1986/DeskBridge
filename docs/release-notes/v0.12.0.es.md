- Disposición: Detectar pantallas vuelve a leer las pantallas de cada equipo conectado y muestra en cada una cuál es, con el nombre y el color de su equipo; en el mapa cada pantalla lleva el nombre de su equipo.
- Una pantalla apagada o desenchufada se conserva como desconectada, con lo que hacen con ella los perfiles, en vez de borrarse. DeskBridge lee las pantallas de este PC de Windows al arrancar y abre con el perfil aplicado seleccionado.
- Las ventanas de un equipo que quedan encima de la imagen del sobremesa en su pantalla se pueden usar donde están: el ratón pasa a ese equipo sobre ellas. Las que se abren detrás de la imagen se llevan a donde llega el ratón.
- Una tablet puede mostrar la pantalla del portátil, retransmitida a través del sobremesa, con el cursor siguiéndola; la pantalla de bloqueo y los avisos de administrador también se ven en una pantalla cedida.
- Correcciones: las pantallas virtuales se colocan como las muestra el mapa (una ventana arrastrada fuera de una ya no aparece en otra pantalla); una pantalla principal cedida deja otra utilizable; no queda ninguna pantalla virtual sobrante en la configuración de pantalla de Windows.
