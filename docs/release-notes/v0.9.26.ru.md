- Новый вид: боковая панель со страницей для каждой части приложения.
- Звук: звук другого ПК слышен на координаторе, со своей громкостью, а микрофон координатора работает на другом ПК (с VB-CABLE).
- Более плавные общие экраны: меньше задержка, указатель рисуется сразу, правильные цвета, почти нет сетевого трафика при неподвижном экране и параметр для показа изображения без ожидания обновления экрана.
- Экран блокировки и запросы администратора: необязательная служба позволяет видеть их и управлять ими с координатора; «Запускать от имени администратора» передаёт клавиатуру и мышь приложениям, открытым от имени администратора.
- Раскладка: щелчок правой кнопкой по экрану делает его основным для его компьютера; каждый экран можно отметить цветом его компьютера.
- Устанавливается как приложение (меню «Пуск», Параметры > Приложения) и обновляется удалённо с координатора.
