- Раскладка: «Найти дисплеи» заново считывает дисплеи каждого подключённого компьютера и показывает на каждом, какой это дисплей, с именем и цветом его компьютера; на карте у каждого дисплея подписано имя его компьютера.
- Выключенный или отсоединённый дисплей сохраняется как отключённый, вместе с настройками профилей, а не удаляется. DeskBridge при запуске считывает дисплеи этого ПК из Windows и открывается с применённым профилем.
- Окна компьютера поверх изображения настольного ПК на его экране можно использовать там, где они находятся: мышь переходит к этому компьютеру над ними. Окна, открывшиеся под изображением, переносятся туда, куда достаёт мышь.
- Планшет может показывать экран ноутбука, ретранслируемый через настольный ПК, и курсор следует за ним; экран блокировки и запросы администратора тоже видны на одолженном дисплее.
- Исправления: виртуальные дисплеи располагаются так, как показывает карта (окно, вытащенное за край одного, больше не попадает на другой экран); одолженный основной дисплей оставляет другой, которым можно пользоваться; в параметрах дисплея Windows больше не остаётся лишнего виртуального дисплея.
