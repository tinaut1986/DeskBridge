- Планшет или телефон на Android может показывать один из экранов настольного ПК как ещё один монитор (с приложением DeskBridge для Android, пока в разработке).
- «Подключение и безопасность»: QR для телефона подключает его без ввода общего ключа; если отсканировать его камерой, приложение откроется уже заполненным.
- Компьютер без собственного цвета больше не получает цвет, который уже есть у другого компьютера.
- Исправления: экран, показанный на другом компьютере, остаётся отдельным экраном при смене основного дисплея (раньше он становился копией основного); мышь больше не застревает, возвращаясь на такой экран; выбранный экран на карте в разделе «Раскладка» заметно выделен в тёмной теме.
