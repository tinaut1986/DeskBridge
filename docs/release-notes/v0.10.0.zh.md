- 台式机现在可以在笔记本上显示它的一个屏幕：笔记本的屏幕成为又一台显示器，放在布局地图上它所在的位置。
- “暂停屏幕共享”和“独立电脑”（在主页和通知区域菜单中）可在不更改配置的情况下关闭共享；紧急情况下，在任意电脑上按 Ctrl+Alt+Shift+Home 即可启用“独立电脑”。
- 当一台电脑关机、重启或离开网络时，其他电脑会察觉，停止显示它，并在它回来时继续，网络变化后也是如此。
- 每台需要 Virtual Display Driver 的电脑都会提示安装；它停止时会自动重启，并会补上缺少的分辨率。
- 修复：更改主显示器重新可用；屏幕边框保持颜色、位于任务栏之上，并且只在有其他电脑连接时显示；锁屏服务在更新后会重新启动。
- 显卡驱动停止工作时给出清楚的提示，而不是一遍又一遍地重试。
