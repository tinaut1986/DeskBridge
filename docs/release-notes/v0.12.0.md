- Layout: Detect displays reads every connected computer's displays again and shows on each screen which one it is, with its computer's name and colour; on the map every display carries its computer's name.
- A display that is turned off or unplugged is kept as disconnected, with what profiles do with it, instead of being removed. DeskBridge reads this PC's displays from Windows when it starts, and opens on the profile in place.
- A computer's own windows on top of the desktop's picture on its screen can be used where they are: the mouse goes to it over them. Those that open behind the picture are moved where the mouse reaches them.
- A tablet can show the laptop's screen, relayed through the desktop, with the cursor following; the lock screen and administrator prompts are shown on a lent display too.
- Fixes: virtual displays are placed as the map shows them (a window dragged off one no longer lands on another screen); a lent primary display leaves a usable one; no leftover virtual display stays in Windows' display settings.
