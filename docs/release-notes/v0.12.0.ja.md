- レイアウト: 「ディスプレイを検出」で接続中の各マシンのディスプレイを読み直し、各画面にどのディスプレイかを、そのマシンの名前と色で表示します。マップでは各ディスプレイにマシン名が付きます。
- 電源が切れた、またはケーブルが外れたディスプレイは、削除されずに切断として保持されます (プロファイルでの設定もそのまま)。DeskBridge は起動時にこの PC のディスプレイを Windows から読み取り、適用中のプロファイルで開きます。
- マシンの画面上でデスクトップ PC の映像の上にあるそのマシンのウィンドウは、その場で使えます: その上ではマウスがそのマシンに移ります。映像の裏に開いたウィンドウは、マウスが届く場所へ移動されます。
- タブレットにノート PC の画面を、デスクトップ PC 経由で中継して表示でき、カーソルも追従します。ロック画面と管理者の確認も、貸し出したディスプレイに表示されます。
- 修正: 仮想ディスプレイがマップのとおりに配置されます (端から出したウィンドウが別の画面に現れなくなりました)。貸し出したメインディスプレイの代わりに使えるディスプレイが残ります。Windows のディスプレイ設定に余分な仮想ディスプレイが残らなくなりました。
