- An Android tablet or phone can show one of the desktop's screens, as one more monitor (with the DeskBridge Android app, still in development).
- Connection and security: a QR for a phone joins it without typing the shared key; scanned with its camera, the app opens with everything filled in.
- A computer without a colour of its own no longer gets one another computer already has.
- Fixes: a screen shown on another computer stays a screen of its own when the primary display changes (it became a copy of the main one); the mouse no longer gets stuck coming back onto such a screen; the selected display on the Layout map is outlined visibly on the dark theme.
