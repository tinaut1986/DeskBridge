- Disposição: Detectar telas lê de novo as telas de cada máquina conectada e mostra em cada uma qual ela é, com o nome e a cor da sua máquina; no mapa, cada tela leva o nome da sua máquina.
- Uma tela desligada ou desconectada do cabo é mantida como desconectada, com o que os perfis fazem com ela, em vez de ser removida. O DeskBridge lê as telas deste PC no Windows ao iniciar e abre no perfil aplicado.
- As janelas de uma máquina sobre a imagem do desktop na tela dela podem ser usadas onde estão: o mouse passa para essa máquina sobre elas. As que abrem atrás da imagem são levadas para onde o mouse alcança.
- Um tablet pode mostrar a tela do notebook, retransmitida pelo desktop, com o cursor acompanhando; a tela de bloqueio e os avisos de administrador também aparecem em uma tela emprestada.
- Correções: as telas virtuais ficam onde o mapa as mostra (uma janela arrastada para fora de uma não aparece mais em outra tela); uma tela principal emprestada deixa outra utilizável; nenhuma tela virtual sobrando fica nas configurações de tela do Windows.
