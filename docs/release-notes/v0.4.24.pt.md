- Um só teclado e mouse para vários PCs: leve o cursor além da borda de uma tela para passar ao outro computador; Ctrl+Alt+Home sempre o traz de volta.
- Mostre a tela de um PC no monitor de outro: o notebook cria uma tela virtual (Virtual Display Driver) transmitida com baixa latência para o monitor que você escolher.
- Aba Disposição: posicione as telas dos outros computadores na sua mesa com tamanho e escala reais, e escolha nos perfis o que cada monitor mostra.
- Área de transferência e arquivos compartilhados entre os computadores (desativado por padrão), com uma conexão criptografada protegida por uma chave compartilhada.
- Funciona com um firewall que você não pode alterar: o computador por trás dele se conecta para fora ao coordenador.
- Atualiza-se sozinho a partir destas versões.
