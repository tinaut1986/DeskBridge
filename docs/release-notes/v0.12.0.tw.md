- 配置：「偵測螢幕」會重新讀取每台已連線電腦的螢幕，並在每個螢幕上顯示它是哪一個，帶有所屬電腦的名稱和顏色；地圖上每個螢幕都標有所屬電腦的名稱。
- 關閉或拔掉的螢幕會保留為已中斷連線（連同設定檔中的設定），而不會被刪除。DeskBridge 啟動時從 Windows 讀取本機的螢幕，並開啟目前套用的設定檔。
- 一台電腦螢幕上位於桌機畫面之上的本機視窗可以就地使用：滑鼠在它們上方時會切換到這台電腦。在畫面後面開啟的視窗會被移到滑鼠能到達的地方。
- 平板可以顯示筆電的螢幕（經桌機轉送），游標會跟隨；鎖定畫面和系統管理員提示也會顯示在借出的螢幕上。
- 修正：虛擬螢幕依地圖所示的位置排列（從一個螢幕拖出的視窗不再出現在另一個螢幕上）；借出主螢幕後會留下另一個可用的主螢幕；Windows 顯示器設定中不再殘留多餘的虛擬螢幕。
