- 桌上型電腦現在可以在筆電上顯示它的一個螢幕：筆電的螢幕成為多一台顯示器，放在配置地圖上它所在的位置。
- 「暫停螢幕共用」和「獨立電腦」（在首頁和通知區域選單中）可在不變更設定的情況下關閉共用；緊急情況下，在任何電腦上按 Ctrl+Alt+Shift+Home 即可啟用「獨立電腦」。
- 當一台電腦關機、重新啟動或離開網路時，其他電腦會察覺，停止顯示它，並在它回來時繼續，網路變更後也是如此。
- 每台需要 Virtual Display Driver 的電腦都會提示安裝；它停止時會自動重新啟動，並會補上缺少的解析度。
- 修正：變更主螢幕重新可用；螢幕邊框保持顏色、位於工作列之上，而且只在有其他電腦連線時顯示；鎖定畫面服務在更新後會重新啟動。
- 顯示卡驅動程式停止運作時給出清楚的訊息，而不是一再重試。
