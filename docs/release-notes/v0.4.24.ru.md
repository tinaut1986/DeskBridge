- Одна клавиатура и мышь для нескольких ПК: уведите курсор за край экрана, чтобы перейти на другой компьютер; Ctrl+Alt+Home всегда возвращает его.
- Показывайте экран одного ПК на мониторе другого: ноутбук создаёт виртуальный экран (Virtual Display Driver), который с малой задержкой передаётся на выбранный монитор.
- Вкладка «Раскладка»: разместите экраны других компьютеров на своём столе в реальном размере и масштабе и выберите в профилях, что показывает каждый монитор.
- Общий буфер обмена и файлы между компьютерами (по умолчанию выключено) через зашифрованное соединение, защищённое общим ключом.
- Работает с брандмауэром, который нельзя изменить: компьютер за ним сам подключается к координатору.
- Обновляется сам из этих выпусков.
