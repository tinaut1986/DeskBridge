- Un seul clavier et une seule souris pour plusieurs PC : poussez le curseur au-delà du bord d'un écran pour passer à l'autre machine ; Ctrl+Alt+Origine le ramène toujours.
- Affichez l'écran d'un PC sur le moniteur d'un autre : le portable crée un écran virtuel (Virtual Display Driver) diffusé avec une faible latence sur le moniteur de votre choix.
- Onglet Disposition : placez les écrans des autres machines sur votre bureau à leur taille et échelle réelles, et choisissez dans les profils ce qu'affiche chaque moniteur.
- Presse-papiers et fichiers partagés entre les machines (désactivé par défaut), via une connexion chiffrée protégée par une clé partagée.
- Fonctionne derrière un pare-feu que vous ne pouvez pas modifier : la machine derrière se connecte elle-même au coordinateur.
- Se met à jour toute seule depuis ces versions.
