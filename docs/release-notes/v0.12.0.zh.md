- 布局：“检测显示器”会重新读取每台已连接机器的显示器，并在每个屏幕上显示它是哪一个，带有所属机器的名称和颜色；地图上每个显示器都标有所属机器的名称。
- 关闭或拔掉的显示器会保留为已断开（连同配置文件中的设置），而不会被删除。DeskBridge 启动时从 Windows 读取本机的显示器，并打开当前应用的配置文件。
- 一台机器屏幕上位于台式机画面之上的本机窗口可以就地使用：鼠标在它们上方时会切换到这台机器。在画面后面打开的窗口会被移到鼠标能到达的地方。
- 平板可以显示笔记本电脑的屏幕（经台式机中转），光标会跟随；锁屏界面和管理员提示也会显示在借出的显示器上。
- 修复：虚拟显示器按地图所示的位置排列（从一个显示器拖出的窗口不再出现在另一个屏幕上）；借出主显示器后会留下另一个可用的主显示器；Windows 显示设置中不再残留多余的虚拟显示器。
